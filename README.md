# Sur Mesure

**Beauty, made to measure.**

Sur Mesure is a beauty-tech web application that uses facial landmark analysis and measurable facial proportions to create personalized makeup placement recommendations. Built around the idea that makeup is not one-size-fits-all, the project combines computer vision, data analysis, and web development to tailor recommendations to each user's unique features.

## Why I Built It

Most makeup placement advice relies on broad categories such as "round face" or "almond eyes." I wanted to explore whether facial measurements and landmark data could be used to create recommendations that are more individualized.

Sur Mesure is also a personal learning project designed to strengthen my skills in web development, data analysis, computer vision, and information systems.

## Current Features

- Upload a front-facing image
- Detect a face using MediaPipe Face Landmarker
- Extract 478 facial landmarks
- Convert normalized landmark coordinates into image coordinates
- Visualize detected landmarks directly on the uploaded image

## In Development
